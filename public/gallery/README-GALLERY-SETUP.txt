AALCS Gallery Folder Structure

Place this entire 'gallery' folder inside your website's 'public' folder:

public/gallery/

Each service/package has 5 job folders:
job-1
job-2
job-3
job-4
job-5

Each job folder contains:
before/
after/

Example:
public/gallery/mowing/standard-residential-lawn-maintenance/job-1/before/before-1.jpg
public/gallery/mowing/standard-residential-lawn-maintenance/job-1/after/after-1.jpg

Recommended photo naming:
before-1.jpg
before-2.jpg
before-3.jpg

after-1.jpg
after-2.jpg
after-3.jpg

You can add more than 3 photos if needed.
Just keep the names simple and consistent.
